Episode 1 of *Can Flexprice Handle It?* recreates Replit's pricing in Flexprice from scratch. Replit runs a hybrid model, so subscriptions, usage-based compute credits, feature gating and credit grants all have to work together. The episode builds the whole setup through the Flexprice MCP server and Claude in four to five minutes.

## How Replit's pricing maps to Flexprice

| Replit's pricing uses | Flexprice setup |
| --- | --- |
| **Subscription tiers** with a monthly fee | [Plans](/docs/product-catalogue/plans/overview) with a recurring charge |
| **Usage-based compute credits** | [Metered features](/docs/product-catalogue/features/create) with usage charges on each plan |
| **Features gated by tier** | [Entitlements](/docs/product-catalogue/features/linking-to-plans) that grant or limit each feature per plan |
| **Credit grants that differ by plan** | Recurring credit grants on each plan, which add credits to the customer's [wallet](/docs/wallet/prepaid-and-promotional) |

## Building Replit's pricing with the MCP server

The episode connects Claude to Flexprice through the [MCP server](/docs/connect/mcp-server) and describes Replit's plans in a conversation. Claude creates the features, plans, prices and entitlements. Details that need a human decision can be finished afterward through the API or the dashboard.
