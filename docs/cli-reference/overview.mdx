Commands follow a consistent shape:

```sh
flexprice <resource> <action> [flags]
```

Run `flexprice resources` to see this list from your terminal, or `flexprice <resource> --help` for a single resource.

For flags accepted by every command, see [Global flags](/docs/cli/global-flags).
