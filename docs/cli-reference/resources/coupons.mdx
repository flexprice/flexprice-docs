## create

Create coupon

| Flag | Type | Required |
|---|---|---|
| `--amount_off` | string |  |
| `--cadence` | string | yes |
| `--coupon_code` | string |  |
| `--currency` | string |  |
| `--duration_in_periods` | integer |  |
| `--max_redemptions` | integer |  |
| `--name` | string | yes |
| `--percentage_off` | string |  |
| `--redeem_after` | string |  |
| `--redeem_before` | string |  |
| `--type` | string | yes |

<Note>
These fields are nested and cannot be set with flags. Use `--edit` to fill in a pre-built request body, or `--data @file.json`.

- `metadata` (object)
- `rules` (object)
</Note>

```sh
flexprice coupons create --cadence=<value> --name=<value> --type=<value>
```

## delete
