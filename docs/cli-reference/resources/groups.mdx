## create

Create group

| Flag | Type | Required |
|---|---|---|
| `--entity_type` | string | yes |
| `--lookup_key` | string | yes |
| `--name` | string | yes |

```sh
flexprice groups create --entity_type=<value> --lookup_key=<value> --name=<value>
```

## delete

Delete group

```sh
flexprice groups delete
```
