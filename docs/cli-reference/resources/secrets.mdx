## create

Create a new API key

| Flag | Type | Required |
|---|---|---|
| `--expires_at` | string |  |
| `--name` | string | yes |
| `--service_account_id` | string |  |
| `--type` | string | yes |

```sh
flexprice secrets create --name=<value> --type=<value>
```

## delete

Delete an API key

```sh
flexprice secrets delete
```

## list

List API keys

```sh
flexprice secrets list
```
