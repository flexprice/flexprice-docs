The Flexprice Model Context Protocol (MCP) server provides a set of tools that AI agents can use to interact with the Flexprice API: customers, plans, subscriptions, invoices, payments, events, and more.

## What is the Flexprice MCP server?

- An MCP server that exposes your Flexprice API as **MCP tools** so AI assistants can call your API without reading REST docs.
- **Hosted by Flexprice.** Add your region's URL to your MCP client. There is nothing to install or run.
- **Log in with your browser**, or send an API key when your client or agent cannot log in.
- Works with any MCP client that supports remote servers: Claude Code, Claude Desktop, Cursor, VS Code, Windsurf, Antigravity, and others.

You can also [run the server yourself](#running-the-mcp-server-yourself) with npx: for a self-hosted Flexprice, to limit tools with `--scope`, or for clients that only run local servers.

## MCP server URLs

| Region | Dashboard | MCP server URL |
| --- | --- | --- |
| US | `us.flexprice.io` | `https://mcp.us.flexprice.io/mcp` |
| India | `admin.flexprice.io` | `https://mcp.in.flexprice.io/mcp` |

Use the URL for the region your account was created in, the one whose dashboard you log in to. The examples on this page use the US URL. India accounts use `https://mcp.in.flexprice.io/mcp` instead.

## Authenticating the MCP server

There are two ways to authenticate.

**Browser login (recommended).** Add the URL with no credentials. The first time your client connects, it opens the Flexprice dashboard in your browser. Log in, pick the environment the assistant should work in, and click **Authorize**. Every tool then works in that environment only. To switch environment, remove the server from your client and add it again.

**API key.** Send your key in the `api-key-auth` header. The server then works in the key's environment. Use this for clients without browser login and for agents that run unattended. Create keys in the dashboard under **Developers**. See [Manage API keys](/docs/rbac/manage-api).

<Note>
  Each region has its own accounts and keys. An India account cannot log in through the US URL, and a US key does not work on the India URL.
</Note>

## MCP server security and credentials

- With browser login, the assistant can do anything your user can do, in the environment you picked.
- To limit an agent, use an API key with a restricted role, or [run the server yourself](#running-the-mcp-server-yourself) with `--scope read`.
- Do not commit API keys. Rotate a key if it is ever committed or exposed.
- We recommend enabling human confirmation for write or destructive operations in your MCP client.

<Warning>
  We advise caution when giving LLMs write access to production data. Always
  review actions before execution. Use caution when using the Flexprice MCP with
  other servers to avoid prompt injection attacks.
</Warning>

## Installing the Flexprice MCP server

### Installing in Claude Code

Add the server for your region:

<CodeGroup>
```bash US
claude mcp add --transport http flexprice https://mcp.us.flexprice.io/mcp
```

```bash India
claude mcp add --transport http flexprice https://mcp.in.flexprice.io/mcp
```
</CodeGroup>

Then run `claude`, type `/mcp`, select **flexprice**, and choose **Authenticate**. Your browser opens the Flexprice dashboard to log in and pick an environment. See [Claude Code MCP documentation](https://docs.anthropic.com/en/docs/claude-code/mcp).

To use an API key instead, add a header:

```bash
claude mcp add --transport http flexprice https://mcp.us.flexprice.io/mcp --header "api-key-auth: YOUR_API_KEY"
```

Manual installation:

1. Open **Cursor → Settings → Cursor Settings** and go to the **MCP** tab.
2. Click **+ Add new global MCP server** (or open `~/.cursor/mcp.json`) and add:

```json
{
  "mcpServers": {
    "flexprice": {
      "url": "https://mcp.us.flexprice.io/mcp"
    }
  }
}
```

3. Save. Cursor asks you to log in: follow the prompt and log in to Flexprice in your browser. See [Cursor MCP documentation](https://docs.cursor.com/context/model-context-protocol).

To use an API key instead, add a `headers` object next to `url`:

```json
{
  "mcpServers": {
    "flexprice": {
      "url": "https://mcp.us.flexprice.io/mcp",
      "headers": {
        "api-key-auth": "YOUR_API_KEY"
      }
    }
  }
}
```

### Installing in VS Code

1. Open the Command Palette (**Ctrl+Shift+P** / **Cmd+Shift+P**) and run **MCP: Open User Configuration**.
2. Add the following. See [VS Code MCP documentation](https://code.visualstudio.com/docs/copilot/chat/mcp-servers).

```json
{
  "servers": {
    "flexprice": {
      "type": "http",
      "url": "https://mcp.us.flexprice.io/mcp"
    }
  }
}
```

3. Start the server. VS Code asks you to log in to Flexprice in your browser.

To use an API key instead, add `"headers": { "api-key-auth": "YOUR_API_KEY" }` next to `url`.

### Installing in Antigravity

The Antigravity CLI (`agy`), IDE, and app read MCP servers from the same file.

1. Open `~/.gemini/config/mcp_config.json`, or create it if it does not exist. In the IDE, you can also click **…** at the top of the agent panel, select **MCP Servers**, then **Manage MCP Servers** → **View raw config**.
2. Add the server. See [Antigravity MCP documentation](https://antigravity.google/docs/mcp).

```json
{
  "mcpServers": {
    "flexprice": {
      "serverUrl": "https://mcp.us.flexprice.io/mcp"
    }
  }
}
```

3. Log in. In the CLI, run `agy`, type `/mcp`, select **flexprice**, and choose **Authenticate**. In the IDE or app, open Agent settings, go to the **Customizations** tab, and click **Authenticate** next to **flexprice**. Log in to Flexprice in your browser and pick an environment, then paste the code Antigravity shows back into Antigravity.

To use an API key instead, add `"headers": { "api-key-auth": "YOUR_API_KEY" }` next to `serverUrl`.

### Installing in Windsurf

1. Open Windsurf Settings → Cascade → **Manage MCPs** → **View raw config**.
2. Add the server. See [Windsurf MCP documentation](https://docs.windsurf.com/windsurf/cascade/mcp).

```json
{
  "mcpServers": {
    "flexprice": {
      "serverUrl": "https://mcp.us.flexprice.io/mcp"
    }
  }
}
```

To use an API key instead, add `"headers": { "api-key-auth": "YOUR_API_KEY" }` next to `serverUrl`.

### Installing in other MCP clients

Any client that supports remote (Streamable HTTP) MCP servers can connect with your region's URL. Clients that support MCP authorization open the browser login. Otherwise, send your key in the `api-key-auth` header.

In Claude Desktop, add Flexprice as a custom connector:

1. Open **Settings → Connectors** and click **Add custom connector**.
2. Enter the name `Flexprice` and your region's MCP server URL.
3. Click **Connect** and log in to Flexprice in the browser window that opens.

Custom connectors cannot send an API key header. To use Claude Desktop with an API key, [run the server yourself](#running-the-mcp-server-yourself).

## Running the MCP server yourself

Run the server on your own machine when you:

- use a self-hosted Flexprice,
- want to limit tools with `--scope` or `--mode dynamic`, or
- use a client that only runs local (stdio) servers.

This needs Node.js 20 or later and an API key.

```bash
npx -y @flexprice/mcp-server start --server-url https://us.api.flexprice.io/v1 --api-key-auth YOUR_API_KEY
```

<Warning>
  `--server-url` is the Flexprice **API** base URL, not the MCP URL:

   - **US Region:** `https://us.api.flexprice.io/v1`
   - **India Region:** `https://api.cloud.flexprice.io/v1`
   - **Self-hosted:** your host, for example `http://localhost:8080/v1`

  Include `/v1` and no trailing slash.
</Warning>

In an MCP client config file (Cursor, Windsurf, Claude Desktop, and most others):

```json
{
  "mcpServers": {
    "flexprice": {
      "command": "npx",
      "args": [
        "-y",
        "@flexprice/mcp-server",
        "start",
        "--server-url",
        "https://us.api.flexprice.io/v1",
        "--api-key-auth",
        "YOUR_API_KEY"
      ]
    }
  }
}
```

In Claude Code:

```bash
claude mcp add flexprice -- npx -y @flexprice/mcp-server start --server-url https://us.api.flexprice.io/v1 --api-key-auth YOUR_API_KEY
```

**Config file locations:** Claude Desktop (macOS): `~/Library/Application Support/Claude/claude_desktop_config.json`; Windows: `%APPDATA%\Claude\claude_desktop_config.json`. Save the file and restart the client.

**Limit the tools.** Add `"--scope", "read"` to the arguments for read-only access. Repeat `--scope` to combine `read`, `write`, and `delete`. Without `--scope`, every tool is mounted. Add `"--mode", "dynamic"` to expose three discovery tools (`list_tools`, `describe_tool_input`, `execute_tool`) instead of one tool per operation.

## What can you ask the MCP server?

Once connected, you can ask your AI assistant to:

- "List my customers" or "Get customer by id …"
- "Create a subscription for customer … on plan …"
- "Get plan by id …" or "List plans"
- "Get usage for subscription …"
- "Which environment are you working in?" (browser login only)

## Which tools the MCP server exposes

The server exposes the Flexprice API as MCP tools (one tool per OpenAPI operation). We recommend enabling human confirmation of tools and exercising caution when using the Flexprice MCP with other servers to avoid prompt injection attacks.

| Resource      | Example tools                                                                |
| ------------- | ---------------------------------------------------------------------------- |
| Customers     | `get_customers`, `post_customers`, `get_customers_id`                        |
| Plans         | `get_plans`, `get_plans_id`, `post_plans`                                    |
| Subscriptions | `post_subscriptions`, `get_subscriptions_id`, `post_subscriptions_id_cancel` |
| Invoices      | `get_invoices`, `get_invoices_id`, `post_invoices`                           |
| Payments      | `get_payments`, `post_payments`                                              |
| Events        | `post_events`, `post_events_bulk`                                            |
| Features      | `get_features`, `post_features`                                              |
| Prices        | `get_prices`, `post_prices`                                                  |
| Wallets       | `get_wallets_id`, `post_wallets_id_top_up`                                   |

With browser login, the server also adds `get-current-environment`, which returns the environment the connection works in.

For the full list, see your MCP client's tool list after connecting or the [API Reference](/api-reference/introduction).

## Troubleshooting the MCP server

| Symptom | Fix |
| --- | --- |
| Server does not appear | Save the MCP config and restart your client. |
| Login opens, but your account is not accepted | The URL is for the other region. Use `mcp.us.flexprice.io` for US accounts and `mcp.in.flexprice.io` for India accounts. |
| "No environment is selected for this connection" | Remove the server from your client, add it again, and pick an environment on the **Authorize** page. |
| Working in the wrong environment | Ask the assistant which environment it uses. To change it, remove the server, add it again, and pick another environment when you log in. |
| API key rejected on the hosted server | Send it in the `api-key-auth` header, and use the MCP URL of the region the key was created in. |
| Invalid URL or 404 (running it yourself) | `--server-url` must be the API base URL with `/v1` and no trailing slash, for example `https://us.api.flexprice.io/v1`. |
| API or connection errors | Verify your API key. Test it with `curl -H "x-api-key: YOUR_KEY" https://us.api.flexprice.io/v1/customers`. |
| Rate limiting | Reduce request frequency or contact Flexprice support. |
