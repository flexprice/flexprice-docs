Use **Pricing Table** to show a comparison table of multiple plans, with billing period and currency controls built in.

  </Tab>
  <Tab title="Code">
    ```tsx
    const plans: Plan[] = /* fetch + map */;

    <PricingTable
      plans={plans}
      billingPeriod={period}
      onBillingPeriodChange={setPeriod}
      billingPeriodOptions={[{ label: 'Monthly', value: 'MONTHLY' }]}
      currency={currency}
      onCurrencyChange={setCurrency}
      currencyOptions={[{ label: 'USD', value: 'USD' }]}
      onSelectPlan={(planId) => router.push(`/checkout/${planId}`)}
    />
    ```
  </Tab>

## What PricingTable supports

- Unlimited plans
- Feature comparison
- Usage limits and included entitlements
- Custom pricing units
- Custom CTA
- Recommended plan highlighting
- Billing period and currency controls

## Where to use PricingTable

- Pricing pages
- Documentation
- Sales pages

## Importing PricingTable

```tsx
import '@flexprice/ui/style.css';
import { PricingTable, type Plan } from '@flexprice/ui';
```

## Rendering PricingTable

```tsx
const plans: Plan[] = /* fetch + map */;

<PricingTable
  plans={plans}
  billingPeriod={period}
  onBillingPeriodChange={setPeriod}
  billingPeriodOptions={[{ label: 'Monthly', value: 'MONTHLY' }]}
  currency={currency}
  onCurrencyChange={setCurrency}
  currencyOptions={[{ label: 'USD', value: 'USD' }]}
  onSelectPlan={(planId) => router.push(`/checkout/${planId}`)}
/>
```

Wire `onSelectPlan` to [Checkout](/docs/checkout/checkout-sessions) or your own flow. See [Ways to provide data](/docs/exportable-ui/overview#ways-to-provide-data-to-the-components) for SDK, API, backend, and static JSON options.

## Mapping API data into PricingTable

```ts
import { adaptPlanToCard, filterAndSortPlans } from '@flexprice/ui';

const plans = filterAndSortPlans(plansWithData, 'USD', 'MONTHLY').map((p) =>
  adaptPlanToCard(p, grants)
);
```
