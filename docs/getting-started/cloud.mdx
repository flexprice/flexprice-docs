## Quick Setup

Getting started with Flexprice Cloud is straightforward and requires no infrastructure setup. Follow these simple steps:

1. Visit [Flexprice Cloud](https://admin.flexprice.io/auth)
2. Sign up using either:
   - Google account
   - Email and password

That's it! Your Flexprice Cloud instance is ready to use.

## Setting up API Keys

To integrate Flexprice with your application, you'll need to generate an API key:


<Steps>
  <Step title="Open API keys">
    In the left sidebar, go to **Developers → API keys**.

    <Frame>
      ![API keys page listing secret and publishable keys with their masked values](/images/docs/getting-started/api-keys-page.png)
    </Frame>
  </Step>

  <Step title="Create the key">
    Click **Create API key** and configure your key:

    - **Name**: Give it a descriptive name (e.g., "Development")
    - **Expires on**: Leave it blank for a key that never expires
    - **Type**: **Secret key** for calls from your server. It can do anything your account can. A **Publishable key** is safe to ship in a browser or mobile app, and can only do what a customer may do.

    Click **Create key**.

    <Frame>
      ![New API key dialog with the name Development and the Secret key type](/images/docs/getting-started/create-api-key.png)
    </Frame>
  </Step>

  <Step title="Copy the key">
    **Important**: Copy your API key immediately with **Copy key**. It is shown only once: a lost key has to be revoked and replaced. Then click **I have saved it**.

    <Frame>
      ![Copy this key now dialog showing the new secret key](/images/docs/getting-started/created-api-key.png)
    </Frame>
  </Step>
</Steps>

### Using Your API Key

Include your API key in all requests to Flexprice API:

```bash
curl -X POST https://api.cloud.flexprice.io/v1/customers \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "Example Customer", "external_id": "<your-customer-id>"}'
```

<Warning>
  Keep your API key secure and never expose it in client-side code or public repositories.
</Warning>
