---
title: "Feature grouping"
description: "Assign features to a group when creating or editing a feature."
---

Create a group with **Entity type** **Feature** first ([Creating a group](/docs/product-catalogue/groups/create)). Then assign features to that group using the steps below. In the dashboard, groups are called **tags**.

## Workflow

<Steps>
  <Step title="Assign a tag when creating a feature">
    - Go to **Product catalog** → **Features** and click **New feature**
    - Expand **Optional details** and choose a tag in **Tag** (e.g. "Usage Pricing"). Only tags that hold features are listed
    - Click **Create feature**; the feature is stored with that tag
    <Frame>
      ![Create feature form with a tag chosen under Optional details](/images/docs/groups/feature-tag.png)
    </Frame>
  </Step>

  <Step title="Change the tag on an existing feature">
    - Open the feature, click the **⋯** menu, and select **Edit details**
    - Under **Optional details**, set **Tag** to the tag you want
    - Click **Save changes**
    <Frame>
      ![Edit feature form with the Tag field under Optional details](/images/docs/groups/feature-edit-tag.png)
    </Frame>
  </Step>
</Steps>

<Note>
  The dashboard can't remove a feature's tag. To ungroup a feature, update it through the API with `group_id: ""`.
</Note>

## API (features)

| Action     | Method | Endpoint             |
|------------|--------|----------------------|
| Create     | POST   | `/v1/features`       |
| Update     | PUT    | `/v1/features/:id`   |
| Get feature| GET    | `/v1/features/:id`   |
| Search     | POST   | `/v1/features/search` |

**Create:** Optional `group_id`. Group must exist and have `entity_type: "feature"`. Response includes `group_id` and `group`.

**Update:** Send `group_id: "group_..."` to assign, `group_id: ""` to ungroup. Omit to leave unchanged.

**Get:** Response includes `group_id` and `group` when the feature is in a group.

**Search:** Each item has `group_id` and `group` when set. Filter by group: `field: "group_id", operator: "eq", value: { "string": "<group_id>" }` (or `operator: "in"` with array).

### Where reflected

The **Usage breakdown** on the [Customer Portal](/docs/customers/customer-portal#usage) **Usage** tab groups features by tag, with each tag's total cost. Features without a tag are listed under **Other**.
